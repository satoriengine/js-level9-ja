# JavaScriptレベル9

レベル8では、GoFの23パターンのうち、オブジェクト指向の基礎となる8つのパターンを学びました。このレベル9は、その続編として、レベル8では扱わなかったパターンをさらに5つ取り上げます。

取り上げるのは、代理オブジェクトを通じてアクセスを制御するプロキシパターン、複雑な処理をシンプルな窓口にまとめるファサードパターン、そしてレベル8のオブザーバーパターンをさらに発展させ、発行者と購読者を仲介者（EventBus）で切り離すPub/Subパターンです。加えて、JavaScriptがクラスの多重継承を持たないことから生まれた実務的な工夫であるミックスインパターン、そして承認フローのように「担当者を順番にたらい回しにする」構造を表現する責任の連鎖パターンも扱います。

レベル8と同様、各パターンは「困る例」から出発し、写経しながら段階的に理想の形へ近づけていく流れで構成されています。最後の7章では、5つのパターンのうち4つをテーマを変えて出題する、総合的な練習問題に取り組みます。

## 内容
JavaScriptレベル9では以下のテーマを取り扱います。

* プロキシパターン
* ファサードパターン
* Pub/Subパターン（Observerとの違い）
* ミックスインパターン
* 責任の連鎖パターン（Chain of Responsibility）

「ECMAScript2015」以降に準拠していますが、本カリキュラムでは上記の分野のみを取り扱います。
