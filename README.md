# JavaScriptレベル9

{{説明文}}

## 内容
JavaScriptレベル9では以下のテーマを取り扱います。

* プロキシパターン
* ファサードパターン
* Pub/Subパターン（Observerとの違い）
* ミックスインパターン
* 責任の連鎖パターン（Chain of Responsibility）

「ECMAScript2015」以降に準拠していますが、本カリキュラムでは上記の分野のみを取り扱います。

## 対象
JavaScriptレベル9は以下のような方を対象にしています。

* 初めてプログラミングを学習する方
* JavaScriptの学習が初めての方

## 前提条件
前提条件として以下のような学習を推奨します。

* JavaScriptレベル1を履修済み
* JavaScriptレベル2を履修済み
* JavaScriptレベル3を履修済み
* JavaScriptレベル4を履修済み

* JavaScriptレベル6を履修済み
